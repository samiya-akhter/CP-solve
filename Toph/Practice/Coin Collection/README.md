## Problem Statement

Never had Rafy thought of collecting all the different coins of Wonderland, but his dream came true. He managed to gather every single coin from Wonderland’s vast collection. All the value of the coins are distinct.

Now, Rafy is eager to share his treasure with you, and he needs your help to figure out the exact position of each coin in sorted order. More formally, he wants them arranged in ascending order.

Your task is to help Rafy determine the correct position of each coin in the collection.

## Input

The first line contains a single integer n (2<=n<=10⁵) — the number of different coins.

The second line contains n integers aᵢ (1<=aᵢ<=10⁹) — aᵢ is the value of the i th coin.

The third line contains a single integer q (0<=q<=10⁵) — the number of queries.

Each of the next q lines contains a single integers X — a coin from the coins list.

## Output

For each query, output the exact position of the coin X once the collection is sorted in ascending order.
