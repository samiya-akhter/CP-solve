## Problem Statement

You will be given an array **a** of **n** positive integers. You have to count the number of nonempty subarray where the sum and the XOR (bitwise XOR) of that subarray are equal. A subarray is the sequence of consecutive elements of the array. An array **b** is a subarray of an array **a** if **b** can be obtained from **a** by deletion of several (possibly, zero or all) elements from the beginning and several (possibly, zero or all) elements from the end. Note that, an array is a subarray of itself.

## Input

Next line contains an integer n(1 ≤ n ≤ 10⁶), the size of the array **a**.

Next line contains n integers a₁, a₂…, aₙ(1 ≤ aᵢ ≤ 10¹⁸).

## Output

In one line, print the number of nonempty subarray where the sum and the XOR of that subarray are equal.

## Sample Tests

**Sample Input:**

```
3
2 3 1000
```

**Sample Output:**

```
4
```
