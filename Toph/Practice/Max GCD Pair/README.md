## Problem Statement

You are given an array of N integers. Your task is to find the maximum possible GCD (Greatest Common Divisor) that can be obtained from any pair of elements in the array.

The GCD of two integers is the largest number that divides both of them exactly (without leaving a remainder).
For Example: GCD(12, 18) = 6

## Input

1. The first line contains an integer N — the number of elements in the array.
(2 ≤ N ≤ 10⁵)
2. The second line contains N integers: a₁, a₂, ..., aₙ,
where 1 ≤ aᵢ ≤ 10⁶

## Output

Print a single integer — the maximum GCD among all possible pairs in the array.

## Sample Tests

**Sample Input:**

```
4
8 2 3 6
```

**Sample Output:**

```
3
```
