## Problem Statement

A Coupon is a string consisting of exactly six digits (from `'0'` to `'9'`). A Coupon is said to be **Fantaboulus** if the sum of the first three digits is equal to the sum of the last three digits.

Given a string representing the Coupon, determine whether it is **Fantaboulus** or **Not Fantaboulus**.

## Input

The first line of the input contains an integer t (1≤t≤10³) — the number of testcases.

The description of each test consists of one line containing one string consisting of six digits.

## Output

Print t lines, each containing `"YES"` if the given coupon is *`Fantaboulus`* , or `"NO"` otherwise. Each answer must be printed on a separate line corresponding to its test case.

## Sample Tests

**Sample Input:**

```
5
100100
961123
445556
213312
000100
```

**Sample Output:**

```
YES
NO
NO
YES
NO
```
