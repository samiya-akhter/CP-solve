## Problem Statement

In the judge room, everyone is worried about the contestants. So, the judges created a new game consisting of Q rounds.

In each round, there are N + 1 consecutive integers, but you are only given N of them in any order. Your task is to determine the missing integer.
The given input guarantees that the missing number always exists and is unique.

## Input

The first line contains a single integer Q (1 ≤ Q ≤ 100), the number of rounds.

For each round:

- The first line contains an integer (2 ≤ N ≤ 100), the number of elements in array A.
- The second line contains N integers where, each 1 ≤ A[i] ≤ 1000.

## Output

For each round output the missing number in a new line.

## Sample Tests

**Sample Input:**

```
1
3
4 5 7
```

**Sample Output:**

```
6
```
